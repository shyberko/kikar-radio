# רדיו כיכר — מערכת ניהול שידור

מערכת לשי (משתמש יחיד) שמחברת בין הפידים של [כיכר השבת](https://www.kikar.co.il) לבין התחנה [Kikar Radio](https://radiocast.kikar.co.il) ב־AzuraCast 0.23.8.

הממשק בעברית, מימין לשמאל: [shyberko.github.io/kikar-radio](https://shyberko.github.io/kikar-radio/).

## מה המערכת עושה

- **סריקה** של `category/vod/feed` ו־`category/music/feed`. קובץ השמע לא יושב ב־RSS; הסורק פותח את הכתבה ולוקח את `contentUrl` מסוג `https://stream.kikar.co.il/<uuid>/play_480p.mp4`, יחד עם אורך, פוסטר ושם הסדרה. התוצאה נשמרת ב־`data/catalog.json`.
- **בחירה** של פריט לחלון שידור: היום, השבוע (עד יום ו׳ ב־23:59 שעון ירושלים) או החודש. בסיום החלון הפריט יורד מהפלייליסט והקובץ נשאר בשרת.
- **העלאה** פעם בשעה (בדקה 05) וגם ידנית עם «העלה עכשיו». ההמרה היא MP3 ב־192kbps עם `loudnorm` ותגיות ID3, אל התיקיות `kikar-auto/vod` ו־`kikar-auto/music`.
- **מבזק שעתי** מהפיד `kikar-scoop-news`. בדיקה כל חמש דקות. מהדורה חדשה מחליפה את הקודמת בפלייליסט «כיכר אוטו – מבזק שעתי». מהדורה רלוונטית רק 60 דקות משעת ה־HH:00 שלה, גם אם המהדורה הבאה לא עלתה.
- **פרסומות, ג׳ינגלים ומעברונים** עולים ישר מהדפדפן ל־AzuraCast (בלי להמתין ל־Actions), עם תדירות וגם שעות קבועות. קמפיין שתאריך הסיום שלו עבר נכבה אוטומטית.

פלייליסטים שהמערכת יוצרת מתחילים ב־«כיכר אוטו –» ומסומנים `managed-by:kikar-radio`. הפלייליסט `election` וכל פלייליסט אחר לא נוצרים, לא נערכים ולא נמחקים.

## הגדרה חד־פעמית

1. ב־AzuraCast: תפריט המשתמש → **My API Keys** → מפתח חדש. המפתח לאוטומציה כבר שמור בסודיות הריפו בשם `RADIOCAST_API_KEY`. אין להדביק אותו לקוד.
2. ב־GitHub: Fine-grained personal access token **רק** למאגר `shyberko/kikar-radio`, עם הרשאות **Contents: Read and write** ו־**Actions: Read and write**.
3. לפתוח את [הממשק](https://shyberko.github.io/kikar-radio/). באשף:
   - שלב 1 — כתובת `https://radiocast.kikar.co.il` והמפתח של AzuraCast. «בדוק חיבור».
   - שלב 2 — הטוקן של GitHub. «בדוק».
   - שלב 3 — שיוך סדרות, או דילוג.
4. המפתחות נשמרים רק ב־`localStorage` של הדפדפן הזה. «נתק ומחק מפתחות» בהגדרות מוחק אותם.

GitHub Pages כבר מוגדר כ־workflow. דחיפה ל־`main` תחת `site/` מפרסמת את האתר.

## מסכים

| מסך | מה עושים שם |
|---|---|
| בחירה | כרטיסים לפי VOD / מוזיקה, טווח, סדרה וסטטוס. החלקה ימינה מאשרת, שמאלה מדלגת. «אשר» מאשר מיד עם ברירת המחדל. ⋯ פותח חלון. יש ביטול, בחירה מרובה ומקלדת. |
| בשידור | תור, כשלונות, מה שכבר בפלייליסט, וכרטיס המבזק השעתי עם היסטוריית 12 שעות. |
| פלייליסטים | רק פלייליסטים של המערכת: הפעלה, סדר ומשקל, וטקסט לוח זמנים. |
| כללים | בונה משפט. כלל המבזק נעול. כללים אוטומטיים חלים על פרקים חדשים. |
| פרסומות | קמפיין עם תאריכים, תדירות ו/או שעות קבועות; ג׳ינגלים וסוויפרים עם מתג. |

קיצורי מקלדת (כשלא מקלידים): `A` אשר, `S` דלג, `E` חלון, רווח נגן, `X` בחירה, `U` העלה עכשיו, `1`–`5` מעבר מסך, `?` עזרה. בלי חיבור, הפעולות נכנסות לתור מקומי בלי כפילויות ונשלחות כשהרשת חוזרת.

## לוחות זמנים

| תהליך | מתי | קובץ |
|---|---|---|
| סריקת פידים | כל 15 דקות | `.github/workflows/scan.yml` |
| העלאה | כל שעה בדקה 05, וגם ידנית | `.github/workflows/upload.yml` |
| מבזק | כל 5 דקות | `.github/workflows/bulletin.yml` |
| בדיקת חיבור | ידנית: מעלה קובץ ל־`_test/` ומוחק אותו | `.github/workflows/test-upload.yml` |
| אתר | בדחיפה ל־`main` | `.github/workflows/pages.yml` |

«העלה עכשיו» מפעיל את `upload.yml` עם מזהה הפריט. אם אין פריטים בתור הכפתור כבוי.

## קבצי נתונים

- `data/catalog.json` — מה שהסורק מצא
- `data/selections.json` — אישורים ודילוגים מהממשק
- `data/rules.json` — כללים ושיוך סדרות
- `data/auto-approvals.json` — אישורים אוטומטיים מכללים
- `data/ads.json` — קמפיינים, ג׳ינגלים, מעברונים
- `data/bulletin-control.json` — השהיית מבזק
- `data/system.json` — מזהי הפלייליסטים שנוצרו
- `data/status/` — זמני העלאה אמיתיים, כשלונות, והיסטוריית מבזק

הממשק כותב בחירות, כללים, פרסומות והשהיית מבזק דרך GitHub Contents API. השרתים של Actions כותבים קטלוג וסטטוס, כדי שלא ידרסו זה את זה.

## פיתוח מקומי
